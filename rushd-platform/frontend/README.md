# واجهة روافد العقارية

واجهة React 19 + Vite، باللغة العربية واتجاه RTL.

## تواصل الإدارة — P07

اضبط `VITE_PUBLIC_CONTACT_PHONE` و`VITE_PUBLIC_WHATSAPP_PHONE` بصيغة دولية كاملة مثل `+966…` في إعدادات البناء/ملف محلي متجاهل. القيم عامة للزوار وليست أسرارًا؛ الافتراضي في `.env.example` فارغ فيخفي الإجراء المقابل. الرقم المعتمد محليًا في [تقرير P07](../docs/p07-administration-contact-verification.md). عند النشر اضبط الإعدادين في بيئة البناء ولا تعتمد على نقل `.env.local`، ثم أعد البناء. لا تضع أسرار JWT أو بيانات حسابات في VITE_*.

## مرشحات التصفح — P08

`/properties` يستخدم city/district/type/listingType/rentalPeriod/minPrice/maxPrice/page من API الحالي، ضمن أسماء مكة المعتمدة. حجم الصفحة 12 والأحدث أولًا؛ تحفظ الحالة في الرابط وعند العودة من التفاصيل. تعديل المسودة يخفي النتائج ويلغي طلبها حتى التطبيق الصريح. لا نطاق سعر مع أنواع/فترات مختلطة؛ تغيير وحدة السعر يحتاج مراجعة المبالغ أو مسحها. الحي هنا مطابقته حرفية كما في API، وليس توحيد بادئة «حي» في المطابقة الشخصية. [الملفات والنتائج وحدود التحقق](../docs/p08-catalog-filters-verification.md).

## صور العقارات — P11/P12

بعد حفظ العقار يبقى محرره مفتوحًا ويظهر قسم مستقل لرفع JPEG/PNG ومعاينتها وإدارة ترتيبها ورئيسيتها وحذفها. حفظ الصور منفصل عن حفظ المواصفات، وتبقى الملفات عند الفشل ما دامت الصفحة مفتوحة. طلب واحد لكل ملف، مع حقوق نشر وإقرار، حتى 12 صورة و8MiB للمصدر وفق عقد الباكند. الإلغاء يوقف انتظار العميل ولا يضمن إلغاء حفظ الخادم؛ إعادة المحاولة تحافظ على الرمز والبيانات لمنع التكرار.

الصورة الرئيسية في بطاقات التصفح والإدارة والمطابقة، ومعرض قابل للاستخدام بلوحة المفاتيح في التفاصيل. الصور تمر عبر Axios بالكوكيز وCSRF عند الكتابة، دون روابط تخزين عامة أو تخزين دائم في المتصفح. العقار بلا صور يبقى صالحًا؛ فشل الصور لا يخفي المواصفات. [شرح الملفات والاختبارات والقيود](../docs/p11-p12-property-images-ui-verification.md).

الميزة الخلفية **معطلة افتراضيًا**. الترقية والتخزين الخاص يحتاجان تفعيلًا معتمدًا منفصلًا؛ لا تنفذ SQL على قاعدة المشروع لتجربة الواجهة دون اعتماد. طابور الملفات ومتابعة التنظيف المعلق مؤقتان في ذاكرة الصفحة، لا حفظ دائم أو استعادة تلقائية بعد مغادرتها.

## المفضلة الشخصية — P13/P14

صفحة `/favorites` وأزرار حفظ/إزالة في التصفح والتفاصيل والمطابقة. حالة البطاقات بطلب GET دفعة واحدة، والكتابة عبر PUT/DELETE والكوكيز وCSRF الحاليين. لا نجاح قبل204، وإعادة المحاولة الغامضة تكرر العملية نفسها بدل عكس الحالة. يمسح مخزن الحساب عند الخروج/تغيره ويهمل الردود المتأخرة، دون localStorage أو تخزين JWT.

العقار المخفي يظهر دون عنوان أو سعر أو صورة، مع إزالة فقط؛ لا يتسرب من المفضلة. الزائر يدعى للدخول ثم يعود لمسار محلي موثوق دون حفظ تلقائي. الميزة معطلة افتراضيًا في الباكند إلى حين اعتماد ترقية وتفعيل مستقلين؛503 لا يعني قائمة فارغة. [API](../docs/api-favorites.md) و[شرح الملفات والاختبارات](../docs/p13-p14-favorites-verification.md).

## التصميم المعتمد

تلتزم جميع الصفحات بـ[نظام التصميم](../docs/design.md): الأحمر العنابي `#8F3038` والبيج `#EFE2C9` مع خلفية بيج ونص داكن.

- الألوان والقواعد المشتركة: `src/index.css`.
- خط الموقع: Thmanyah Sans محلي بصيغة WOFF2 في `src/assets/fonts/thmanyah/`، دون تحميل Google Fonts؛ إعداد الأوزان في `src/index.css` وpreload للوزن400 في `index.html`.
- العلامة والتنقل والتذييل والأيقونات: `src/components/`.
- الرئيسية: `src/pages/Home.jsx` و`Home.css`.
- العقارات والدخول ولوحة التحكم: `src/pages/` و`Pages.css`.
- الهوية الظاهرة وعنوان المتصفح والأيقونة: «روافد العقارية».
- لا تستخدم أنماطًا محلية أو ألوانًا مستقلة تناقض متغيرات التصميم.

قدم صاحب المشروع ملفات الخط وأكد إذن تضمينها كخط ويب في18 أكتوبر2026؛ راجع قيد الترخيص ومسؤولية توثيق الإذن قبل النشر في [نظام التصميم](../docs/design.md#مصدر-الخط-وحدود-التضمين). لا تعدل ملفات الخط أو تعيد نسبتها للمشروع.

نتائج اختبارات الأصول ومعاينة الكمبيوتر والجوال وحدود التحقق موثقة في [تقرير تطبيق الخط](../docs/font-integration-verification.md).

## الصفحات الحالية

| المسار            | الحالة                                          |
| ----------------- | ----------------------------------------------- |
| `/`               | صفحة تعريفية، معاينة توضيحية، وفحص اتصال الخدمة |
| `/properties`     | مرشحات مكة والحي والنوع والسعر والعرض والفترة، وصفحات محفوظة في URL |
| `/properties/:id` | مواصفات العقار ومعرض صوره المسموح بها أو بديل بلا صور |
| `/login`          | دخول فعلي باستخدام HttpOnly cookies                       |
| `/dashboard`      | إضافة وتعديل مواصفات وصور للأدمن فقط؛ حساب عادي للتصفح |
| `/favorites`      | مفضلة شخصية للمسجل، بصفحات وعناصر غير متاحة دون بيانات |
| `/compare`        | مقارنة عقارين أو ثلاثة، أنواع مختلفة ووحدات أصلية، دون حفظ دائم أو تقييم |

AuthProvider يستعيد الحساب من /api/auth/me. يستخدم Axios cookies مع withCredentials، وتجديدًا تلقائيًا واحدًا مع CSRF؛ لا تخزين JWT في JavaScript. الباكند يفرض صلاحيات ADMIN. نموذج الإيجار يدعم سعرًا شهريًا أو سنويًا. لا حساب أدمن افتراضي ولا نشر بائع.

المقارنة منفذة في [P15](../docs/p15-property-comparison-verification.md) للزائر والمسجل عبر GET التفاصيل الحالي، دون تعديل قاعدة؛ الاختيارات مؤقتة وتُمسح عند reload أو تغير الحساب، ولا تحويل فترات أو ترتيب سعري. المفضلة منفذة في P13/P14 وتعتمد تفعيل باكندها بعد ترقية معتمدة. التحليل ما زال مخططًا. تستخدم الصفحات نفس الهوية والمكونات مع مراجعة الكمبيوتر والجوال ولوحة المفاتيح.

راجع [عقد المصادقة](../docs/api-auth.md) لترقية cookies وCSRF. اضبط VITE_API_BASE_URL عند الحاجة. شغّل npm test لفحص التجديد المتزامن.
