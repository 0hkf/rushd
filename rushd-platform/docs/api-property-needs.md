# عقد احتياجات المستخدم — R1

`POST /api/property-needs/validate` يراجع الاحتياجات ويعيد ملخصًا منظمًا فقط. لا يبحث عن عقارات، ولا يحسب ملاءمة أو سعرًا، ولا يحفظ الاحتياجات، ولا يتصل بـAI.

## الوصول والخصوصية

- يتطلب حسابًا مسجلًا ودخولًا فعليًا عبر access cookie الحالية، مع CSRF في `X-XSRF-TOKEN`، كما في [عقد المصادقة](api-auth.md).
- طلب مجهول مع CSRF صالح يحصل على `401`؛ CSRF غائب أو غير صالح ينتج `403` قبل التحقق من الجسم. الحقول غير الصالحة تنتج `400`.
- الواجهة `/property-needs` تعرض النموذج للمسجلين فقط؛ التصفح العام للعقارات لم يتغير.
- الاحتياجات في ذاكرة الصفحة فقط. الخروج أو تغير الحساب يمسح النموذج، وتغيير المدخلات أو مسحها يزيل الملخص السابق. لا localStorage أو sessionStorage أو جدول احتياجات.
- الانتقال بعد الدخول يسمح فقط بالمسارين المحليين `/dashboard` و`/property-needs`؛ لا تحويل إلى عنوان خارجي من `returnTo`.
- الطلبات المعتادة لا تدور رمز CSRF لمجرد إعادة بناء مصادقة JWT؛ الدخول والتجديد والخروج ما زالت تمسحه، والعميل يجلب رمزًا جديدًا بعدها. فحص CSRF لم يعطل لأي مسار.

## المدخلات

| الحقل | القاعدة |
|---|---|
| `listingType` | مطلوب صراحة: `SALE` أو `RENT`، لا افتراضي |
| `rentalPeriod` | `MONTHLY` أو `YEARLY` مطلوب للإيجار؛ null أو غائب للبيع |
| `type` | مطلوب: `LAND/APARTMENT/VILLA/BUILDING/COMMERCIAL/FARM/OTHER` |
| `maxBudget` | مطلوب، من `0.01` إلى `99999999999999999.99`، حتى منزلتين عشريتين؛ ريال سعودي بحسب فترة العرض |
| `city` | اختياري/null، أو `مكة المكرمة` بالضبط؛ أي مدينة أخرى أو نص فارغ يرفض. الواجهة لا ترسله، والخادم يحدد النطاق |
| `district` | اختياري، حتى 100 حرف بعد إزالة المسافات الطرفية؛ الفراغ/null يتحول إلى null |
| `districtRequirement` | `REQUIRED` أو `PREFERRED`؛ افتراضي `PREFERRED` مع حي، وnull دونه؛ لا قيمة غير null دون حي |
| `minArea/maxArea` | اختياريان، من `0.01` إلى `9999999999.99` وحتى منزلتين عشريتين؛ الأدنى لا يتجاوز الأعلى |
| `areaRequirement` | `REQUIRED` أو `PREFERRED`؛ افتراضي `REQUIRED` مع أي حد مساحة، وnull دون حدود؛ لا قيمة غير null دون نطاق |
| `searchGoal` | اختياري: `RESIDENTIAL/INVESTMENT/COMMERCIAL/AGRICULTURAL/OTHER`؛ نية المستخدم، وليست تصنيف `purpose` للعقار |

الأرقام في الطلب يمكن أن تكون أرقام JSON أو سلاسل عشرية؛ الواجهة ترسل سلاسل لتحافظ على الدقة وتطبع الأرقام العربية/الفارسية إلى الصيغة العشرية. أي حقل إضافي غير مدعوم يرفض بـ`400` في هذا العقد وحده، دون تغيير معالجة JSON للعقارات القديمة.

قيم enum تقبل الأسماء النصية الدقيقة فقط؛ الأرقام والترتيب العددي كسلسلة والكسور والقيم المنطقية ترفض. الحدود الرقمية الصريحة تمنع تجاوز فحص عدد الخانات بصيغ أسية ضخمة.

نص الحي ليس اختيار Google ولا معرف حي موحدًا. توحيد الأحياء وربطها بالمخزون عمل لاحق. معنى المساحة المسجلة يحتاج توثيقًا بحسب نوع العقار قبل المقارنة والترشيح، ولا يفترض أنها مساحة صافية أو إجمالي بناء لكل الأنواع.

## مثال إيجار شهري

```json
{
  "listingType": "RENT",
  "rentalPeriod": "MONTHLY",
  "type": "APARTMENT",
  "maxBudget": "4500.50",
  "district": "  النوارية  ",
  "districtRequirement": "PREFERRED",
  "minArea": "120",
  "maxArea": "180",
  "areaRequirement": "REQUIRED",
  "searchGoal": "RESIDENTIAL"
}
```

استجابة `200`:

```json
{
  "listingType": "RENT",
  "rentalPeriod": "MONTHLY",
  "type": "APARTMENT",
  "maxBudget": "4500.50",
  "district": "النوارية",
  "districtRequirement": "PREFERRED",
  "minArea": "120",
  "maxArea": "180",
  "areaRequirement": "REQUIRED",
  "searchGoal": "RESIDENTIAL",
  "city": "مكة المكرمة",
  "currency": "SAR",
  "areaUnit": "SQUARE_METRE"
}
```

القيم العشرية في الاستجابة سلاسل دائمًا، لا أرقام JavaScript عائمة. الحقول الاختيارية الغائبة تعاد null. لا `id` ولا `results` ولا `score`؛ هذه الاستجابة ليست توصية أو تقييمًا.

## التحقق

اختبارات R1 تغطي الأنواع السبعة، الوصول وCSRF، توافق فترة الإيجار، الحدود والدقة العشرية، نطاق المساحة، الحقول غير المدعومة، تطبيع الاختياري، وعدم استدعاء مستودع العقارات أو حفظ المستخدم. اختبار الترشيح الفعلي ومرجع السوق ليس جزءًا من هذا المسار.

التحقق المحلي: 150 اختبار باكند و18 اختبار واجهة ناجحة، مع نجاح البناء والفحص وتجربة HTTP ومتصفح على H2 مؤقت. التفاصيل والحدود في [نتيجة R1](requirement-01-user-needs.md).

لا أعمدة أو ترقية قاعدة بيانات أو dependencies جديدة مطلوبة لـR1. المصادقة وترقياتها السابقة ما زالت مطلوبة عند تشغيل المشروع على قاعدة قديمة.
