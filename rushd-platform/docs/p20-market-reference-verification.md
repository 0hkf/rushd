# P20 — إدارة مراجع السوق: العقد المنفذ والتحقق

11 نوفمبر 2026. النطاق والإصدارات والأرشفة ورفع الأصل معتمدة صراحة. التنفيذ تجريبي معطّل افتراضيًا؛ لا ترقية ولا تفعيل ولا بيانات سوق على قاعدة المشروع الفعلية، ولا commit/merge/push.

## النتيجة وحدودها

صفحة `/admin/market-references` لإدارة مصادر وزارة العدل وملاحظات صفقات البيع بالريال في مدينة مكة، مشتركة بين حسابات ADMIN. لا أسعار إيجار أو جلب روابط أو استيراد صفوف أو تحليل أسعار أو AI. عدم اكتمال النوع التفصيلي أو معنى المساحة يبقى ظاهرًا ولا يستنتج من كلمة «سكني». لا تعيد API علامة `eligible` أو تقييمًا للسعر، حتى إن كانت جميع الحقول معبأة.

بيانات المصدر ثابتة منذ إنشائه في هذه النسخة، وليس بعد الرفع فقط. تصحيح بياناته يعني إنشاء مصدر جديد وأرشفة القديم؛ لا API لتغييرها. هذا اختيار محافظ يحفظ provenance. تاريخ التغيير UTC، وحدود تاريخ الإدخال بحسب اليوم في الرياض. تواريخ الواجهة ميلادية صريحة بصيغة `YYYY-MM-DD` مع عزل اتجاهها في RTL؛ لم نعتمد على منتقي تاريخ المتصفح الذي تعذر إدخاله بثبات في المتصفح المدمج أثناء التجربة.

## فصل المسؤوليات

- `MarketController`: مسارات ADMIN، قراءة JSON محدودة بـ16KiB، ردود `no-store`، مرفق خاص باسم مولّد، وتحويل أخطاء العقد إلى HTTP. CSRF وcookies وCORS من الحماية الحالية دون تعديل.
- `MarketInput`: عقد محلي صارم، مفاتيح معروفة فقط، رفض المفاتيح المكررة، أسماء enum فقط، حدود النصوص والتواريخ والمجال العشري. لا تعديل لإعدادات JSON العامة أو عقود Property.
- `MarketWorkflow`: يعيد فحص دور الحساب المخزن، ويحدد الفاعل من الجلسة، وينظم معاملات الإنشاء والتعديل والأرشفة. رقم مراجعة قديم يرفض بـ409، ولا ينتج إصدارًا جديدًا. الإنشاء بمعرف UUID ثابت وبصمة للطلب يقبل إعادة المحاولة المطابقة، حتى من أدمن آخر. قفل المصدر يسبق قفل المرجع في الإنشاء والتعديل وتغيير الحالة، لمنع سباق أرشفة المصدر مع فحص جاهزيته وبترتيب أقفال موحد.
- `MarketStore`: JDBC بمعاملات ومعاملات SQL مربوطة، وأربعة جداول منفصلة. لا تستعلم القوائم بايتات الأصل. قفل صف الحصة يجعل فحصها وحجزها والرفع عملية واحدة، وقفل رأس المرجع يحمي تنافس محررين.
- `XlsxEnvelope`: فحص ZIP محدود، مع مطابقة الفهرس المركزي وأسماء العناصر المحلية، ورفض traversal والماكرو والعناصر الثنائية والروابط الخارجية والتشفير وZIP غير المدعوم. XML descriptors فقط مع تعطيل DTD/XXE؛ لا قراءة صفوف ولا استخراج إلى القرص. 2048 عنصرًا و64MiB حد فك إجمالي و1MiB لكل descriptor. ليس مدقق Excel كاملًا أو مضاد فيروسات؛ الإنتاج يحتاج سياسة مستقلة للفحص والعزل والاحتفاظ والنسخ الاحتياطي.
- `marketReferences.js` و`MarketReferences.jsx`: إدخال/إرسال/عرض العشريات كنصوص، ودعم العربية والفارسية، وتأكيد استبدال النموذج داخل الصفحة. تحفظ المدخلات عند الرفض أو انتهاء الجلسة، ولا يستخدم العميل interceptor تسجيل الخروج العام الذي يهدم المحرر. نتيجة نقل مجهولة/500/502/504 تجمّد العملية وتتيح إعادة الطلب نفسه؛ 409 يطلب إعادة القراءة ولا يكتب فوق نسخة أحدث.

## التخزين

الترقية الإضافية `backend/db/20261111-market-references.sql` في معاملة؛ ترفض إعادة التطبيق أو حالة تطبيق جزئي بدل تخمين المخطط. لا تُشغّل تلقائيًا عند بدء التطبيق.

| الجدول | المحتوى |
| --- | --- |
| market_sources | بيانات إصدار المصدر، bytea خاص ثابت، SHA-256 وحجم من الباكند، أرشفة ومراجعة وهوية الفاعلين والتوقيت |
| market_references | الهوية والمصدر ورقم الصفقة النصي والإصدار الجاري؛ تفرد الرقم داخل المصدر |
| market_reference_versions | snapshots حقائق غير معدلة عبر التطبيق، السعر والمساحة numeric(19,2)، الحالة والسبب والفاعل والتوقيت |
| market_storage_quota | صف وحيد مقفول لحجز حصة الأصول |

السعر مطلوب والمساحة اختيارية، كلاهما موجب من `0.01` إلى `99999999999999999.99`، حتى 17 خانة صحيحة وخانتين عشريتين؛ الكسر الزائد يرفض ولا يقرّب. الطلب يقبل نصًا عشريًا أو رقم JSON دقيقًا عند الخادم، بما فيه الصيغة الأسية المحدودة التي تمثل قيمة ضمن العقد، ويرفض الأس الهائل. الواجهة ترسل صيغة عشرية نصية عادية فقط. الاستجابة دائمًا نص بخانتين عشريتين. مساحة المصدر ليست عمود مساحة Property ذي precision مختلف.

عدد العقارات null أو عدد JSON صحيح 1–1000000؛ لا افتراض أنه واحد، ولا قسمة إجمالي السعر/المساحة. النوع ومعنى المساحة null أو اسمان معتمدان يحتاجان دليلًا نصيًا؛ المعاني: LAND / UNIT_NET / UNIT_GROSS / TOTAL_BUILT. الهوية ورقم الصفقة لا يعدلان بعد الإنشاء. تحديث الحقائق استبدال كامل: يجب تقديم الحقول العشرة كلها، وnull صريح للمجهول.

الأصل حتى 10MiB وحصة جميع الأصول 100MiB. الأرشفة تحتفظ بالأصل والحصة والإصدارات. إعادة نفس البايتات لنفس المصدر لا تكرر الحجز؛ تبديل الأصل بـ409. بصمة SHA-256 تثبت تطابق البايتات لا أصالة المصدر أو سلامته القانونية.

## API

كل المسارات أدناه تحت `/api/admin/market` وتتطلب ADMIN؛ كل كتابة تتطلب إثبات CSRF الحالي. لا يُقبل userId/createdBy في الطلب. صفحة الواجهة ليست طبقة الصلاحيات الوحيدة.

| المسار | الطلب/النتيجة |
| --- | --- |
| GET /sources، GET /sources/{id} | metadata فقط؛ القائمة limit=1..50 وoffset=0..1000000، الافتراضي20/0 |
| POST /sources | UUID ثابت + title/officialUrl/periodStart/periodEnd/obtainedDate/licenceNote/notes؛ 200 عند الإنشاء والإعادة المطابقة |
| PUT /sources/{id}/original | raw application/octet-stream؛ قراءة محدودة، لا multipart؛ لا استيراد |
| GET /sources/{id}/original | application/octet-stream وattachment وnosniff وno-store؛ حتى المؤرشف للأدمن |
| PUT /sources/{id}/state | expectedRevision نص + archived boolean + reason مطلوب |
| GET /references، GET /references/{id} | الإصدار الجاري وmissingData وصفية؛ نفس حدود القوائم |
| POST /references | UUID ثابت + sourceId + sourceReference + جميع حقول الحقائق؛ مصدر جاهز وغير مؤرشف |
| PUT /references/{id} | جميع حقول الحقائق + expectedRevision نص + changeReason؛ إصدار جديد، لا تغيير provenance |
| PUT /references/{id}/state | expectedRevision + archived + reason؛ إصدار جديد للأرشفة/الاستعادة |
| GET /references/{id}/versions | الإصدارات الأحدث أولًا، limit/offset؛ حالة المصدر في missingData حالية وليست حالة تاريخية مزعومة |

400 مدخلات، 401 جلسة، 403 صلاحيات/CSRF، 404 مفقود، 409 تعارض/تكرار رقم داخل المصدر/تبديل أصل/حصة ممتلئة، 413 تجاوز الحجم، 415 نوع نقل غير مدعوم، 503 ميزة معطلة. المعرفات UUID والمراجعات وهوية الفاعلين نصوص في الاستجابة. أحجام الملفات وعدد العقارات أعداد صحيحة صغيرة آمنة في JavaScript.

مثال إنشاء مرجع بعد حفظ المصدر ورفع أصله (قيم اختبار لا أسعار سوق):

```json
{
  "id": "00000000-0000-4000-8000-000000000002",
  "sourceId": "00000000-0000-4000-8000-000000000001",
  "sourceReference": "0009007199254740993",
  "transactionDate": "2026-05-01",
  "city": "مكة",
  "district": null,
  "sourceClassification": "سكني",
  "propertyType": null,
  "areaMeaning": null,
  "evidenceNote": null,
  "price": "99999999999999999.99",
  "area": "9007199254740993.01",
  "propertyCount": null
}
```

تعيد الاستجابة الهوية والمصدر والرقم و`revision: "0"`، والحقائق نفسها داخل `facts`، و`archived:false` والفاعل والتوقيت و`missingData`. هذا المثال ينتج MISSING_DETAILED_TYPE / MISSING_AREA_MEANING / MISSING_DISTRICT / UNKNOWN_PROPERTY_COUNT. لا ينتج حكمًا إيجابيًا على السعر.

## التفعيل والتجربة اليدوية

المفاتيح `rushd.market.enabled` (أو RUSHD_MARKET_ENABLED) و`VITE_MARKET_REFERENCES_ENABLED` كلاهما false افتراضيًا. لم تتغير ملفات .env الخاصة بالمشروع. لا ينفذ أي استعلام market عند تعطيل الباكند. يلزم اعتماد تشغيل مستقل قبل تطبيق SQL أو التفعيل على قاعدة المشروع؛ لا تنسخ أوامر اختبار عشوائيًا إلى قاعدة حقيقية.

في بيئة مؤقتة معتمدة فقط: طبّق الترقية على القاعدة المؤقتة، فعّل المفتاحين في عمليتي الاختبار، ثم ادخل بحساب ADMIN تجريبي. افتح الصفحة، أضف بيانات مصدر رسمي وتواريخ ودليل شروطه، اختر XLSX واضغط رفع صراحة، ثم أضف رقم المرجع وحقائقه. جرّب العربية والفارسية وسعرًا فوق 2^53، واقرأ القيمة المحفوظة، ثم عدّلها بسبب وافتح تاريخ الإصدارات. جرّب الأرشفة والاستعادة بسبب. افتح النسخة نفسها من جلستين؛ تعديل الأولى يجعل الثانية القديمة 409. حساب BUYER والزائر لا يحصلان على بيانات الصفحة/المرفق.

## نتائج التحقق

النتائج النهائية مثبتة بعد مراجعة آخر تعديل، دون ربط قاعدة المشروع. ملاحظة تنفيذ: أُلغيت محاولة اختبار تداخلت مع clean آخر في المجلد المؤقت (class-file-not-found)، وأعيدت الاختبارات تسلسليًا؛ لم يعالج ذلك بتغيير كود المصادقة أو خدمات المستخدم.

| الأمر الفعلي | النتيجة |
| --- | --- |
| mvn -o --batch-mode --no-transfer-progress -DargLine=-javaagent:… clean test في نسخة backend مؤقتة | H2: 764، صفر فشل/خطأ/تخطي؛ 58 حالة جديدة تخص P20 ضمنها التزامن وحجب تعديل مرجع مصدره مؤرشف |
| bash scripts/verify-postgres.sh من النسخة المؤقتة | PostgreSQL16: 764، صفر فشل/خطأ/تخطي؛ validate وقيود الترقيات، ورفض P20 الجزئي وإعادة التطبيق؛ حُذفت الحاوية المملوكة للمشغّل |
| npm test | 353، صفر فشل/تخطي؛ منها17 حالة P20 منطقية وSSR |
| npm run lint | نجاح oxlint |
| npm run build | نجاح مع تعطيل الميزة الافتراضي |
| VITE_MARKET_REFERENCES_ENABLED=true npm run build في نسخة frontend مؤقتة | نجاح بناء الميزة المفعلة أيضًا دون تغيير بيئة المشروع |
| git diff --check | نجاح |

استُخدم Java25 المحلي؛ احتاج Mockito إلى Byte Buddy javaagent الموجود في Maven cache. أُضيف مساره لأوامر التشغيل المؤقتة فقط، لا اعتماد ولا مسار جهاز ثابت في pom أو مشغل المستودع. مشغّل PostgreSQL استخدم الصورة المحلية postgres:16 دون تنزيل، وحاوية جديدة وحيدة الاستخدام وport loopback عشوائي وبيانات مؤقتة؛ لم يعد تشغيل Docker أو يوقف حاويات المستخدم. سجلات هذه الجولة في `/private/tmp/rushd-p20-DXxSO7/`: h2-final.log وpostgres-final.log وfrontend-final.log وlint-final.log وbuild-final.log وbuild-enabled.log. لا تحتوي fixtures أسعار سوق فعلية أو بيانات حسابات المشروع.

المتصفح: H2 مؤقت ببيانات اصطناعية، back127.0.0.1:18097/front127.0.0.1:5179. نجحت إضافة مصدر ورفع XLSX صوري لا يحوي بيانات سوق، وحفظ البصمة والحجم، وتنزيل الأصل وتطابق SHA-256 للبايتات. نجحت إضافة السعر العربي `99999999999999999.99` والمساحة الفارسية `9007199254740993.01`، ورفض `1.001` مع بقاء المدخل، وتعديل السعر وحفظ النسخة الأصلية، والأرشفة والاستعادة، وتأكيد استبدال النموذج مع خيار إبقاء المدخلات. حساب BUYER أعاد «للإدارة فقط» دون النموذج. فُحص عرض390×844 بلا تجاوز أفقي (scrollWidth=390)، وعرض1280×900 وتواريخ RTL. أُغلقت التبويبات والعمليات المؤقتة وأعيد حجم المتصفح؛ لا إبقاء لخدمات الاختبار.

الحدود المتبقية: لا اختبار تحميل إنتاجي، ولا موزع متعدد الخوادم، ولا فحص malware كامل، ولا إدخال ملف مصدر حقيقي أو جميع تنويعات Excel/ZIP. الحصة اختبرت بحدود وعدّاد اصطناعي ورفع متزامن؛ ليس اختبار ملء فعلي لكل100MiB. H2 للمتصفح لا يحل محل نتائج PostgreSQL المنفصلة. لا اختبار استضافة أو نسخ احتياطي أو سياسة احتفاظ قانونية إنتاجية. بناء الواجهة مع تفعيل الميزة نجح مع تحذير Vite عن chunk أكبر من500kB؛ لم يُخف التحذير بتغيير الحد، وتقسيم تحميل الصفحات تحسين أداء لاحق. مراجع الإدخال اليدوي تحتاج مراجعة بشرية؛ P21 يظل متوقفًا عن الحكم السعري بلا عينة مؤهلة وقواعد معتمدة.
