## انتقلت إلى النطاق المطلوب — ليست منفذة بعد

- تحليل الأسعار وتقييم روافد ونقاط القوة والمخاطر.
- تقييم عقار يختاره المستخدم: API التقييم P17 وواجهته P18 منفذان بالقواعد المعتمدة، دون تقييم سوقي؛ نجح اختبار PostgreSQL المعزول في 2 نوفمبر دون المساس بقاعدة المشروع.
- اختيار الموقع والخرائط؛ مزود الخدمة لم يعتمد في الخطة الجديدة. التخزين المتوافق مع Google موجود، دون اتصال Google أو مفتاح.
- تقارير PDF وشرح النتائج.
- تفسير عربي باستخدام نموذج جاهز مستضاف ذاتيًا؛ تجربة Qwen3:4b عبر Ollama مقترحة. محرك الحساب والترشيح وقواعده يسبق النموذج، والاستضافة العامة تحتاج قرارًا.

هذه الميزات تدخل خطة النسخة المستهدفة الجديدة، وليست أعمالًا مؤجلة كلها كما في النطاق السابق.

التنفيذ على مراحل مرنة، بثلاثة أيام عمل أسبوعيًا وميزانية صفر؛ لا موعد لثلاثة شهور. لا نموذج أو استضافة جديدة أو خدمة FastAPI منفذة حتى الآن.

## مؤجلة أو تحتاج اعتمادًا منفصلًا

- طلب اهتمام داخل الموقع ومتابعته بواسطة الإدارة، حسب قرار المستخدم.
- توسيع النطاق إلى مدن أخرى غير مكة.
- إدارة حسابات الأدمن وتدقيق التغييرات.
- عقود الإيجار والحجز والتحصيل والدفع والتجديد.
- حالة «مؤجر» وإدارة توافر عقارات الإيجار؛ الحالات الحالية للنشر فقط.
- تدريب نموذج خاص بحثي بعد التحقق من البيانات والميزانية؛ ليس بديلًا معتمدًا تلقائيًا.
- محادثة داخلية بين المستخدم والإدارة.

الإيجار الحالي عرض سعر شهري أو سنوي، وليس نظام إدارة عقود أو مدفوعات. لا تنفذ هذه البنود تلقائيًا ضمن تعديل الثيم أو العرض.
