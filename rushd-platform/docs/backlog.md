# الأعمال المؤجلة — روافد العقارية

النموذج الحالي: الأدمن يدخل مواصفات عروض البيع والإيجار يدويًا. ليس هناك نشر بواسطة بائع.

## تحتاج نطاقًا مستقلًا

- تحليل الأسعار وتقييم روافد ونقاط القوة والمخاطر.
- مقارنة العقارات والمفضلة.
- التواصل مع إدارة المنصة، وليس حساب بائع.
- صور العقارات ورفع الملفات.
- اختيار الموقع عبر Google Places في الواجهة والخرائط؛ التخزين المنظم موجود دون اتصال Google.
- تقارير PDF وشرح النتائج.
- إدارة حسابات الأدمن وتدقيق التغييرات.
- عقود الإيجار والحجز والتحصيل والدفع والتجديد.
- حالة «مؤجر» وإدارة توافر عقارات الإيجار؛ الحالات الحالية للنشر فقط.

الإيجار الحالي عرض سعر شهري أو سنوي، وليس نظام إدارة عقود أو مدفوعات. لا تنفذ هذه البنود تلقائيًا ضمن تعديل الثيم أو العرض.
