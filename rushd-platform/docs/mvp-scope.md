# نطاق روافد العقارية — تحديث 6 أكتوبر 2026

المرجع الأحدث للقرارات هو [مسودة المتطلبات الجديدة](requirements.md)، مع [خطة بمراحل مرنة](roadmap.md). جميع أنواع العقارات الحالية مطلوبة، والميزانية صفر، والوقت مرن بثلاثة أيام عمل أسبوعيًا. مسار AI المعتمد نموذج جاهز مستضاف ذاتيًا؛ تفاصيل النموذج والنشر لا تزال قيد الاعتماد.

## النموذج المعتمد

المنصة تعرض عقارات للبيع والإيجار. الأدمن المعتمد وحده يضيف العقارات يدويًا ويحدد المواصفات والسعر وحالة النشر. لا يوجد بائع ينشر إعلاناته.

الإيجار شهري أو سنوي حسب العقار؛ السعر هو قيمة الفترة المحددة، وليس سعرًا محسوبًا تلقائيًا أو عقد إيجار أو تحصيل دفعات.

## المنفذ

- خلفية بيج وهوية عنابية موحدة وفق [التصميم](design.md).
- التسجيل العام لحساب BUYER فقط، والدخول باستخدام cookies محمية وتجديد متدوّر.
- حساب ADMIN معتمد خارج التسجيل العام؛ لا يستطيع المستخدم منح نفسه صلاحية الإدارة.
- تصفح العقارات وتفاصيلها من بيانات الباكند.
- إضافة وتعديل العقارات يدويًا بواسطة الأدمن، بما فيها المسودات وحالة النشر.
- عروض SALE للبيع وRENT للإيجار مع MONTHLY أو YEARLY.
- تصفية العروض حسب البيع/الإيجار وفترة الإيجار.
- مواصفات العقار الأساسية وبيانات الموقع المنظمة الاختيارية؛ لا خرائط أو اتصال بخدمات Google.
- نموذج أسئلة لاحتياجات المستخدم على `/property-needs` للمسجلين فقط، مع تحقق في الباكند وملخص، دون حفظ دائم أو محرك ترشيح أو AI. العقد: [api-property-needs.md](api-property-needs.md).

## مطلوب في النسخة المستهدفة وغير منفذ

البداية في مكة لموقع فعلي. يشمل النطاق المطلوب صور العقارات، المفضلة، مقارنة العقارات، اختيار الموقع والخريطة، تقرير PDF، والاتصال والواتساب مع إدارة المنصة.

مساعد شخصي يأخذ احتياجات المستخدم ويرشح من العروض المنشورة، ويبرر الملاءمة والتنازلات ويقيم عقارًا يختاره المستخدم. الباكند يحسب التصفية والترتيب بقواعد واضحة، ونموذج جاهز مستضاف ذاتيًا يشرح الأدلة؛ تجربة Qwen3:4b عبر Ollama مرشحة وليست منفذة أو معتمدة نهائيًا. FastAPI خدمة Python اختيارية، لا بديل تلقائي للباكند الحالي.

حكم ملاءمة الاحتياجات منفصل عن حكم السعر مقارنة بمراجع السوق التي يدخلها الأدمن. دون مرجع صالح لا حكم على السعر. لا تعرض نتائج فعلية أو درجة من 100 قبل اعتماد القواعد وتنفيذها واختبارها. الاستضافة العامة للنموذج وبقية الموقع تحتاج قرار موارد مستقلًا؛ لا وعد بخدمة مجانية مستمرة.

طلبات الاهتمام داخل الموقع مؤجلة صراحة. الدفع وعقود الإيجار والمحادثة والتوسع خارج مكة ليست ضمن النطاق الحالي. التفاصيل في [backlog.md](backlog.md).

## التوافق

العقارات القديمة تعتبر للبيع عند عدم تحديد نوع العرض. بيانات الموقع الجديدة اختيارية. تبقى قيمة SELLER القديمة قابلة للقراءة في قاعدة البيانات دون صلاحية إنشاء أو تعديل أو عرض المسودات. لا نحذف الحسابات أو نغيّر ملكية السجلات تلقائيًا.

راجع [عقد العقارات](api-properties.md) و[المصادقة](api-auth.md) وخطوة ترقية المخطط قبل تشغيل التطبيق على قاعدة قديمة.
