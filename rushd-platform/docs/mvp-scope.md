# MVP Scope - رُشد

هذا الملف يوضح نطاق النسخة الأولى من مشروع رُشد بشكل بسيط وواضح.

## هدف النسخة الأولى

الهدف من النسخة الأولى هو بناء منصة بسيطة تسمح للمستخدم بالتسجيل، تسجيل الدخول، إضافة عقار، تحليل سعر العقار، حساب Rushd Score، مقارنة العقارات، حفظ العقارات في المفضلة، والتواصل مع البائع.

النسخة الأولى لا تحتاج أن تكون كاملة أو متقدمة. المهم أن تقدم تجربة واضحة تساعد المستخدم على فهم القرار العقاري بشكل أفضل قبل الشراء أو الاستثمار.

## Must Have

- Register
- Login
- Roles: Buyer / Seller / Admin
- Add property
- List properties
- Property details
- Calculate price per meter
- Manually enter market average meter price
- Compare property price with market average
- Calculate Rushd Score
- Show strengths
- Show risks
- Compare 2 or 3 properties
- Add property to favorites
- Send interest message to seller

## Nice To Have

- Better dashboard
- Seller public page
- Property image upload
- Advanced filters
- Better UI animations
- Advertisement quality score

## Later
