# حل تعارض المسودات — تنفيذ واختبار معزول

10 نوفمبر 2026. اعتمد المستخدم حفظ النسختين حتى الحفظ الناجح أو الحذف اليدوي، والدمج الصريح مع إعادة فحص المسودة والعقار. الميزة معطلة افتراضيًا؛ لا تطبيق SQL أو تفعيل أو نشر على قاعدة المشروع.

## ما نُفذ

- جدول إضافي `admin_property_draft_conflicts` مرتبط بالمسودة بـFK مع حذف متسلسل؛ يحتفظ بنص نسختي الصفحة والخادم، ولقطة حقول العقار القابلة للتحرير عند انطباقها وبصمتها، ورقم مراجعة المسودة، ونتيجة الدمج دون مسح النسختين الأصليتين.
- 20 مراجعة كحد تجريبي لكل مسودة، و64 KiB لكل لقطة، دون حذف الأقدم تلقائيًا. بلوغ الحد يرفض إنشاء مراجعة إضافية ولا يقص بيانات. مدة بقاء المحتوى تطابق دورة المسودة المعتمدة، ولا توجد عملية انتهاء تلقائي.
- حفظ النسختين لا يعدّل المسودة الأساسية ولا العقار. بعد اختيار المصادر، يتأكد الخادم تحت الأقفال نفسها أن نسخة المسودة وبصمة العقار لم تتغيرا، ثم يحفظ الناتج في المسودة ويحدّث أساس العقار. أي تغيير جديد يعيد 409 دون الدمج.
- المصادر الممكنة: `LOCAL` (الصفحة وقت أرشفتها)، `SERVER` (المسودة وقت المراجعة)، و`PROPERTY` للعقار الحالي عند المراجعة. لا يقبل endpoint الدمج قيمًا عشوائية مكان الخيارات؛ يعيد الخادم بناء الناتج من النسخ المؤرشفة المملوكة فقط.
- لا اختيار افتراضي للمجموعة المختلفة. السعر ونوع العرض وفترة الإيجار والحالة مجموعة، والموقع مجموعة، والمساحة ومصدرها مجموعة، والعمر وسنة تقديره مجموعة. عند اختلاف النوع أو نطاق التجاري تضم مجموعة واحدة النوع والمساحة وجميع المواصفات والمدخلات المؤقتة للأنواع، منعًا لتوليد خليط غير منطبق. باقي الحقول تُختار منفردة مع أخطاء قراءتها.
- المقارنة نصية وتحافظ على المدخلات غير المكتملة والأرقام العربية والفارسية والدقة؛ ليست تحقق نشر. يُراجع الناتج في النموذج ويُطبق تحقق العقار الحالي عند الحفظ النهائي، دون نشر تلقائي.
- إعادة المحاولة بعد فقد الرد تحتفظ بمعرف المراجعة والمحتوى/الخيارات نفسيهما؛ المحرر يتجمد مؤقتًا، ولا يحاول إنشاء عقار. إذا أصبح الخادم أحدث بعد العملية، يرفض تكرار الاستبدال وتُعرض مراجعة جديدة. تبقى النسخ السابقة قابلة للقراءة من نفس الحساب.
- تتوقف مهام الحفظ التلقائي أثناء الدمج، وتنتظر أي طلب جارٍ قبل حفظ اللقطتين؛ لا ترسل مؤقتات قديمة بعد الدمج. يعاد فتح المحرر من النسخة المدمجة المؤكدة.
- الحفظ النهائي للعقار وحذف المسودة وكل نسخ التعارض وإيصال العملية في معاملة واحدة. اختُبر التراجع عند فشل كتابة الإيصال: يبقى المحتوى والأرشيف، ولا ينشأ عقار إضافي.

## API الإضافي

جميع المسارات تحت `/api/admin/property-drafts/{id}`، للأدمن صاحب المسودة فقط، وتُستمد الملكية من الجلسة. معرفات النسخ UUID، والمراجعات نصوص دقيقة. كل كتابة تتطلب CSRF وكل الاستجابات `no-store`. العقود القديمة لا تتغير.

| العملية | العقد |
|---|---|
| `GET /conflicts` | قائمة معرفات المراجعات المحفوظة، دون محتوى اللقطات |
| `GET /conflicts/{conflictId}` | اللقطات والمجموعات ورقم النسخة والنتيجة لصاحبها فقط |
| `POST /conflicts` | `{ "conflictId": "UUID", "localPayload": { "values": {}, "specifications": {} } }`؛ يحفظ نسخة الصفحة والخادم وسياق العقار |
| `POST /conflicts/{conflictId}/resolve` | `{ "choices": { "values.title": "LOCAL", "offer": "SERVER" } }`؛ يلزم كل معرف مجموعة مختلفة كما أعاده الخادم، دون مجموعات مجهولة |

طلبات حفظ/دمج الواجهة تستخدم cookies وCSRF الحاليين دون تشغيل مسار تجديد الجلسة الذي قد يغلق محررًا فيه مدخلات غير مؤكدة. رفض 401/403 لا يمنح وصولًا؛ يظهر الخطأ وتبقى الصفحة. هذا لا يغير سلوك المصادقة العام أو يضمن حفظ غير المؤكد عند إغلاق التبويب قسرًا.

## التحقق الفعلي

- `mvn clean test` في نسخة مؤقتة: 706 اختبارات ناجحة على H2. استُخدم Java agent من الاعتماد الموجود للتوافق مع Java 25.
- المجموعة الأخيرة 706 ناجحة على PostgreSQL 16.11 مؤقت، مع `ddl-auto=validate` وترقيات القاعدة وفحص تكرار الترقية وحجم UTF-8 والحذف المتسلسل؛ أُزيلت الحاوية الخاصة بالاختبار.
- `npm test`: 336 حالة ناجحة؛ `npm run build` و`npm run lint` ناجحان.
- متصفح على H2 وحساب وهمي: تعارض نافذتين، حفظ النسختين، تجميد المدخلات، اختيار مصادر صريح، إعادة فتح المسودة المدمجة، عرض النسختين السابقتين ثم حفظ العقار واختفاء المسودة. بقي السعر `9007199254740993.01` كما هو.
- اختبارات آلية للخيارات الناقصة/غير المسموحة، الحقول المترابطة، تغير العقار أو المسودة، ملكية أدمن آخر وCSRF، ضياع إقرار الأرشفة والدمج وإعادة المحاولة نفسها، والتراجع مع الأرشيف عند فشل الحفظ النهائي.

## حدود ومتابعة

لا استضافة سحابية أو تفعيل للقاعدة الفعلية. تجربة المتصفح كانت نافذتين في جلسة واحدة، لا جهازين مستقلين؛ الجوال وكل صور انقطاع الشبكة لم تختبر بصريًا في هذه الحزمة. الحصص ومعدل الطلبات والنسخ الاحتياطية وإيصالات الحفظ بلا محتوى تحتاج مراجعة تشغيلية قبل النشر. اختيار `PROPERTY` لمدخلات نوع مؤقتة يعرض غيابها صراحة؛ الأصلان يبقيان في الأرشيف حتى نهاية المسودة. لا صور أو AI أو تحليل سوق ضمن هذا التغيير.
