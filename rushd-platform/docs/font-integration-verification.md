# تطبيق خط ثمانية — تحقق18 أكتوبر2026

## النتيجة والنطاق

استبدل Tajawal بـThmanyah Sans على مستوى جذر الواجهة، بما يشمل النصوص والعناوين والترويسة والتذييل والأزرار والمدخلات والقوائم ونماذج الأدمن والاحتياجات. بقيت الهوية البيج/العنابية وRTL كما هي. لم يعد تحميل الخط يعتمد على Google Fonts. لا تعديل للباكند أو API أو قاعدة البيانات أو الصلاحيات أو حزم P04 وما بعدها.

قدم المستخدم مجلد الخط وأكد إذن تضمينه كخط ويب بعد تنبيهه إلى قيود الترخيص؛ هذا تأكيد المستخدم، وليس تحققًا مستقلًا من وثيقة إذن. على مسؤول النشر الاحتفاظ بالإذن والتحقق من تغطيته. النسخة المرفقة محفوظة دون تعديل؛ hashing ليس حماية من استخراج الخط.

## التنفيذ

- أربعة ملفات WOFF2 أصلية: Regular400 وMedium500 وBold700 وBlack900. الوزن800 الموجود في التصميم يربط بملفBold نفسه صراحة، لا Black ولا وزن مصطنع. لا إعادة تسمية للملفات أو تعديل محتواها.
- `@font-face` في `frontend/src/index.css` مع `font-display: swap` وخط نظام احتياطي و`font-synthesis: none`؛ عناصر النماذج ترث خط الجذر.
- تحميل مسبق لـRegular فقط في `frontend/index.html`؛ يعالج Vite المسار إلى الأصل نفسه المستخدم فيCSS وباسم مولد، فلا يتكرر ملف400 بسبب اختلاف المسار.
- إصلاح مباشر لقابلية القراءة: أرقام المواصفات الدقيقة لا تنقسم داخلbdi، وتتحول الشبكة لعمود واحد عندما لا يزيد عرض محتوى بطاقة المواصفات على420px. الاستجابة حسب عرض البطاقة، لا الشاشة وحدها، لمعالجة تضيقها بجانب السعر على الأجهزة المتوسطة.
- لا تحويل للأرقام عبرNumber، ولا تعديل قيم أو منطق تحقق أو تنسيق أو حساب. اتجاه الأرقامLTR داخل واجهةRTL يبقى كما هو.

معاينة متصفح فعلية لناتج بناء إنتاجي مع API تجريبي مؤقت علىloopback؛ لا قاعدة بيانات ولا حسابات أو أسرار حقيقية. شملت الرئيسية والدخول وإضافة/تعديل الأدمن وفتح قسم الموقع وقائمة العقارات والتفاصيل ونموذج الاحتياجات. تحققنا من عائلة الخط المحسوبة لعناصر النماذج ومن`document.fonts.status` ونجاح`document.fonts.check` للأوزان400/500/700/800/900، وليس اسم العائلة وحده.

المقاسات:1280×900،390×844،320×844، وفحص حواف481 و681 و821 و900px. ظهر في الفحص الأول تضيق أعمدة المواصفات عند681؛ صحح باستجابة عرض البطاقة وأعيد فحصه بصريًا. عند481/821/900 كانت الأرقام داخل حدود خلاياها دون تجاوز عرض الصفحة، مع احتفاظ المساحة القصوى `9999999999.99` والسعر `99999999999999999.99` بنصوصهما الدقيقة. بقيت مدخلات عربية `٩٠٠٧١٩٩٢٥٤٧٤٠٩٩٣٫٠١` وفارسية `۱۸۰٫۲۵` كما أدخلت.

أغلقت تبويبات المعاينة وأزيل تجاوز مقاس المتصفح وأوقفت عمليتا المعاينة وحذفت fixtures وبناء الاختبار المؤقت. لم يعد تشغيل خدمات المستخدم أوDocker، ولم تمس قاعدة المشروع. بقي ناتج البناء المعتاد في`frontend/dist`، ولم يستبدل إعداد API الحقيقي بإعداد المعاينة.

## حدود التحقق

هذه معاينة خط وعرض، لا اختبار مصادقة أو حفظ فعلي متكامل؛ صلاحيةADMIN في fixtures لتوفير الشاشة فقط، ولا تثبت أمان الخادم. لم تجر اختباراتMaven أوPostgreSQL في هذه الدفعة لعدم تغييرهما. لم يختبر كل متصفح أو جهاز أو قارئ شاشة، ولم يختبر تعطل طلب الخط يدويًا؛ fallback وswap معرفان فيCSS. لم تفتح الصور أو الخرائط أوAI أو مواصفاتP04، ولم يجرcommit أوmerge أوpush.
