# P02 — التحقق الكامل للمطابقة الحالية على PostgreSQL

التاريخ: 18 أكتوبر 2026. الفرع: `feature/property-google-location`.

## النتيجة

اكتمل P02: نجحت الحزمة الكاملة للباكند **278 اختبارًا** على PostgreSQL16.11 مع المخطط الصريح وHibernate `validate`، و278 على H2، إضافة إلى55 اختبار واجهة وbuild/lint وتجربة متصفح مع PostgreSQL معزول. هذا يغلق فجوة PostgreSQL للمطابقة المشتركة الحالية R1/R3، **وليس اعتمادًا للإطلاق أو اختبارًا لكل البيانات والبيئات الممكنة**.

لا تعديل على `src/main` أو schema أو عقد API أو ترتيب المطابقة أو الأدوار أو CSRF أو إعدادات التشغيل الفعلية. التغيير اختبارات وبيانات اختبار وأداة تحقق وتوثيق فقط. حوفظ على التعديلات السابقة غير الملتزمة، ولم تنسب كلها إلى هذه الحزمة.

## المشكلة والإصلاح

أول `mvn clean test` على PostgreSQL معزول، قبل التعديل:266 اختبارًا،0 failures و7 errors:

1. اختبار المطابقة كان يدرج SALE مع MONTHLY. قيد `ck_property_rental_pricing` يمنعه؛ هذا ليس سجلًا ممكنًا في المخطط الحالي. لم نسقط القيد أو نغير قاعدة الترشيح. أزيل هذا الإدراج فقط، ونقلت تغطية SALE→rentalPeriod IS NULL إلى اختبار Specification بمحاكاة Criteria يتحقق من وجود الشرط في AND النهائي. اختبرت كذلك الفترة الدقيقة للإيجار، مع بقاء تغطية JPA للشهري والسنوي.
2. تنظيف `TokenLifecycleTest` كان يحذف RefreshTokens واحدًا واحدًا بترتيب UUID لا يراعي مرجع `replaced_by_token_id` الذاتي؛ فشلت6 حالات لاحقة في setup. تغير **تنظيف الاختبار فقط** إلى `deleteAllInBatch()` للرموز، ثم الجلسات والمستخدم المحدد كما كان. DELETE واحدة تحذف طرفي سلسلة الاختبار دون إسقاط القيد أو تعديل خدمة المصادقة.

اختبارات المطابقة كانت تعمل flush دون clear؛ كان يمكن أن ترى BigDecimal أو timestamp من ذاكرة JPA بدل قيم PostgreSQL المعاد تحميلها. أصبحت كل مطابقة في الاختبار تعمل flush+clear، وضبطت توقعات scale2 (`200.00` بدل `200`) وقراءة updatedAt من سياق جديد قبل المقارنة. لا تغيير في قيمة الأرقام أو سياسة تقريب الإنتاج.

الصفر/السالب في price/area يمكن أن يوجدا في المخطط الحالي رغم رفض DTO إدخالهما حديثًا، لذلك بقيت اختبارات هذه البيانات القديمة. null area مغطى بمحاكاة الخدمة فقط لأن العمود NOT NULL، وSALE مع فترة مغطى بمحاكاة Specification بدل تجاوز قيد DB.
